# MIHI landing page

Static landing page for MIHI, a friendly AI companion for children.

- `index.html` holds all markup, CSS and the small slider script, with no build step.
- `images/` holds the logo and product images.

Open `index.html` in a browser, or deploy the folder as-is to GitHub Pages, Netlify or Vercel.
The page loads Fredoka, Nunito and Caveat from Google Fonts.
